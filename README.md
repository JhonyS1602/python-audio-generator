🎧 Python Audio Generator

A Python project for generating audiobooks and podcasts using text-to-speech and audio processing.

🚀 About the project

This project explores the automated creation of audio content using Python.

It currently includes tools for:

- Converting text into speech
- Creating audiobook-style audio
- Generating podcast audio
- Processing audio files with Python
